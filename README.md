# Modss на телевизоре

Программа для компьютера в одной сети с телевизором. Она прописывает на роутере адреса `modss.tv`, `api.modss.tv` и `lampa.stream`, которые нашёл сам роутер.

Так телевизор перестаёт открывать адрес Cloudflare, до которого с вашей сети нет ответа. Сайт при этом живой: с телефона в той же сети он обычно открывается. Адрес плагина в Лампе остаётся `http://modss.tv`.

## Как запустить

Скачайте `ModssKeenetic.exe` и откройте его. Python на компьютере не нужен.

Компьютер должен быть в той же сети, что роутер и телевизор.

## Что вписать

| Поле | Что указать |
|---|---|
| Вход | Telnet, SSH или веб-панель Keenetic |
| Адрес роутера | Обычно подставляется сам. Это адрес, по которому вы открываете настройки роутера |
| Порт | Подставляется сам: 23, 22 или 80 |
| Логин и пароль | Ваши, от настроек роутера. Для OpenWrt логин чаще всего `root` |
| Имена | Уже стоят три нужных имени. Можно добавить своё, по одному в строке |

Пароль остаётся только в этом окне и никуда не сохраняется.

На Keenetic служба SSH часто выключена, а Telnet в домашней сети включён. Если Telnet не пускает, выберите «Keenetic, веб-панель».

## Кнопки

**Проверить** — смотрит, какой адрес уже прописан и доходит ли до него роутер. Ничего не меняет.

**Исправить** — снимает старую запись, спрашивает имя у самого роутера и прописывает найденный адрес.

**Удалить записи** — убирает эти имена из DNS роутера.

Если роутер нашёл адрес `188.114.x`, программа его не прописывает: с этого адреса телевизор обычно и не открывает сайт. Если модель роутера не узнана, записи тоже не меняются.

## После исправления

На телевизоре забудьте сеть Wi-Fi, подключитесь к ней снова и откройте `http://modss.tv`. Телевизор несколько минут помнит старый адрес.

## Какие роутеры подходят

Программа сама смотрит ответ роутера и выбирает команды.

- Keenetic — Telnet или веб-панель
- OpenWrt — Telnet или SSH, вход под root
- MikroTik
- DD-WRT
- Asus с прошивкой Asuswrt-Merlin и включённым JFFS

## Из исходников

Нужен Python 3. Для входа по SSH ещё пакет `paramiko`:

```
py -3 -m pip install paramiko
```

Запуск: `Запуск.bat` или `py -3 app.py`.
